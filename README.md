# Python·Git 기초 퀴즈

Python과 Git의 기초 개념을 4지선다 퀴즈로 복습하는 콘솔 프로그램입니다.

## 실행 방법

Python 3이 설치된 환경에서 `python main.py`를 실행합니다.

## 주요 기능

- 기본 4지선다 문제 5개 풀이와 점수 계산
- 문제 추가, 문제 목록, 최고 점수, 종료 메뉴
- `state.json`에 문제와 점수 저장 및 재실행 복원
- 잘못된 번호, 빈 문제, 손상된 JSON 처리
- 저장 중 오류로 파일이 깨지는 것을 줄이기 위한 임시 파일 교체 저장

## 파일 구조

- `quiz.py`: 문제 데이터와 검증을 담당하는 `Quiz`
- `game.py`: 문제 목록과 점수를 관리하는 `QuizGame`
- `storage.py`: JSON 저장·복원과 손상 파일 처리
- `main.py`: 메뉴와 사용자 입력
- `test_quiz.py`: 퀴즈·입력·저장 복원 테스트

리스트는 여러 문제와 보기를 저장하고, 클래스는 문제와 게임 진행의 책임을 나눕니다. `state.json`은 `quizzes`와 `scores` 배열을 저장합니다. 파일이 없거나 손상되면 기본 문제를 사용합니다.

최고 점수 메뉴에서는 최고 점수와 도전 횟수를 함께 보여 줍니다. 문제와 보기의 빈 입력은 저장 전에 거부합니다.

## GitHub 업로드 상태

이 프로젝트는 `kilju0809-art/quiz-mission2` 저장소에 업로드하는 중입니다. 원격 저장소의 기존 README와 병합한 뒤 push합니다.

별도 clone 폴더에서도 README를 수정하고 commit/push한 뒤 원본 작업 폴더에서 pull하는 실습을 완료했습니다.

## 개선점

문제 편집·삭제, 자동 백업, 더 세밀한 데이터 검증을 추가할 수 있습니다. JSON 전체 저장은 데이터가 커지면 데이터베이스가 더 적합합니다.
